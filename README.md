# Scripts-JOSM

Conjunto de ferramentas desenvolvidas para facilitar edições no [JOSM](https://josm.openstreetmap.de/) (Java OpenStreetMap Editor).

## Pré-requisitos

Para executar estes scripts no JOSM, é necessário ter instalado o plugin:
- **JOSM Scripting Plugin**: https://gubaer.github.io/josm-scripting-plugin/

## Documentação e Detalhes dos Scripts

Mais detalhes sobre a função de cada script podem ser encontrados em:
- https://wiki.openstreetmap.org/wiki/User:DressyPear4#Scripts_para_JOSM

*Nota:* Na wiki, alguns scripts ainda estão listados em Python, porém essas versões em Python estão desatualizadas, pois os scripts foram todos migrados para JavaScript.

## Observação

Os scripts neste repositório são escritos e ajustados utilizando Inteligência Artificial (IA).
